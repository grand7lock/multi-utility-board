> 03(한진택배 대량 배송조회), 04(쇼핑몰 주문엑셀 변환기)는 `index.html`에는 등록돼 있으나 위 표에 빠져 있다.

앞으로 약 20개까지 확장 예정. 새 도구는 `tools/`에 페이지를 만들고 `index.html`의 `TOOLS` 배열에 한 줄 추가하면 된다.

`url` 이 `http` 로 시작하면 **바깥 링크**로 보고 새 탭에서 연다(06번이 그 예).
같은 배열에 그냥 한 줄 넣으면 되고, 따로 표시할 것은 없다.

### 카드 순서 바꾸기

카드를 끌어다 놓거나 카드 위의 `◀ ▶` 로 옮길 수 있다. 20칸 전부 움직이며,
빈 칸도 옮겨진다. 바뀐 순서는 **그 브라우저에만** 저장된다(`localStorage`의 `board_layout_v1`).
다른 PC에서는 기본 순서로 보인다. 상단 「기본 순서로」 버튼으로 되돌린다.

저장되는 값은 슬롯마다 도구의 `url` 또는 `null` 인 길이 20 배열이다.
**`TOOLS` 에 새 도구를 추가해도 기존 사용자의 저장된 순서가 깨지지 않는다** —
저장된 배치에 없는 도구는 앞쪽 빈 칸부터 자동으로 채워지고,
`TOOLS` 에서 지운 도구는 배치에서 조용히 빠진다.
`url` 을 바꾸면 그 도구는 새 도구로 취급되어 자리가 초기화되니 주의.

### 05번 도구만의 규칙 — API 키

중국어 번역기는 **API 키를 서버에 두지 않는다.** 각 사용자가 자기 브라우저에 자기 키를
넣고, `api/translate.js`·`api/phrase.js` 는 그 키를 Anthropic 에 넘기기만 한다.
저장도 로그도 하지 않으므로 **주소가 공개돼도 남이 내 크레딧을 쓰지 않는다.**
Vercel 환경변수 설정도 필요 없다.

번역 지시문과 모델은 `api/_shared.js` 한곳에 모여 있다.
`_` 로 시작하는 파일은 Vercel 이 서버리스 함수로 만들지 않으므로 공용 모듈로 안전하다.

페이지 입장 비밀번호는 `tools/image-translate.html` 의 `PASSWORD` 상수(현재 `1212`).
소스보기로 뚫리는 수준이므로 진짜 잠금이 필요하면 Vercel Deployment Protection 을 쓴다.

## 구조

- `index.html` — 대시보드 (20개 슬롯)
- `tools/` — 개별 도구 페이지 (정적 HTML, 데이터는 브라우저 안에서만 처리)
- `api/` — Vercel 서버리스 함수 (외부 API 중계가 필요할 때만 사용)
- `lib/xlsx.full.min.js` — SheetJS (엑셀 생성/파싱 공용 라이브러리)

## 배포

Vercel 정적 + 서버리스 혼합 배포. `npx vercel deploy --prod`.
