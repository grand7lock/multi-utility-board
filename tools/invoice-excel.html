📦 송장 엑셀 생성기

발송 정보를 한 번만 입력하면 한진택배 대량등록 엑셀과 플레이오토 신규주문 업로드 엑셀을 각각 생성합니다.
💡 엑셀에서 붙여넣기 지원: 다른 엑셀에서 범위를 복사한 뒤, 아래 표에서 시작할 칸을 클릭하고 Ctrl+V 하면 여러 행/열이 한꺼번에 입력됩니다. (열 순서: 품목명 → 수량 → 받는 분 → 전화번호 → 우편번호 → 주소 → 특기사항 → 금액)
· 우편번호와 금액은 플레이오토 업로드에만 필요합니다. 한진 엑셀만 쓸 경우 비워도 됩니다.
· 입력 내용은 이 브라우저에 자동 임시저장되어 창을 닫았다 열어도 유지됩니다.

📩 메시지로 한번에 추가

카톡/문자 메시지를 그대로 복사해서 아래에 붙여넣고 분석해서 추가를 누르세요. 여러 건을 한꺼번에 붙여넣어도 됩니다.
인식 형식 예: [한진 발송] → 품목명 → 수량(1개) → 받는 분 → 전화번호 → 주소

공통 설정

No 품목명 수량 받는 분 전화번호 우편번호플레이오토용 주소 특기사항배송메세지 금액플레이오토용
· 한진 엑셀: 출고번호 / 품목명 / 수량 / 받으시는 분 / 받으시는 분 전화 / 받는분총주소 / 특기사항 (기존 대량등록 양식과 동일한 컬럼 배치)
· 플레이오토 엑셀: 37개 컬럼 정식 양식(v14), 필수항목(쇼핑몰주문번호·주문자명·휴대폰·수령자명·휴대폰·우편번호·주소·상품명·주문수량·금액) 자동 채움. 1행이 항목 타이틀이므로 바로 업로드하면 됩니다.
· 받는 분 이름과 전화번호는 플레이오토의 주문자/수령자 항목에 동일하게 들어갑니다.
